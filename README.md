# דאשבורד מלאי ולוגיסטיקה

**כל הנתונים במערכת הומצאו לצורך הדגמה.**

## הפעלה
לחיצה כפולה על `index.html`. אין צורך בהתקנה.

## מבנה
- `src/sources/` מקור הנתונים. מקור אמיתי מממש `load()` ומוחלף בשורה אחת ב-`src/app.js`.
- `src/metrics.js` חישובים.
- `src/forecast.js` תחזיות, בנפרד מהחישובים.
- `src/reconcile.js` בדיקות התאמה, מוצגות במסך "נוסחאות ובדיקות".
- `src/ui/` גרפים, טבלאות וייצוא ל-Excel.
